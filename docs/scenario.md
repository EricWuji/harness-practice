# 练习场景：智能工单分流与SLA预警系统

## 1. 要解决的问题
客户支持团队每天会收到大量工单，人工分拣存在以下痛点：
- 分流慢：高峰时段大量工单堆积；
- 分类不一致：不同坐席判断标准不统一；
- SLA风险滞后：临近超时才被发现；
- 交接成本高：跨班次时上下文信息丢失。

本系统目标是通过AI Agent自动完成工单理解与分流，并在进入风险区间前发出预警。

## 2. 核心能力
- 自动分类：账单 / 故障 / 咨询 / 其他；
- 自动优先级：P1（严重）~ P4（低）；
- 建议处理人：基于技能标签与当前负载；
- SLA预测：根据历史耗时、当前队列、优先级估算超时风险；
- 可审计：记录每次Agent判定依据与版本。

## 3. 关键角色
- Support Agent（人类坐席）：接收建议并可手动修正；
- Routing Agent（AI）：完成分类、优先级、路由建议；
- QA/Reviewer（人类）：抽检样本并审批规则变更；
- Platform Engineer：维护流水线、观测与回滚机制。

## 4. 验收指标（练习用）
- 分类准确率 >= 85%（离线测试集）；
- P1召回率 >= 95%；
- 预警提前量 >= 30分钟（相对SLA截止）；
- 关键流程变更必须100%经过CI与人工审批。
